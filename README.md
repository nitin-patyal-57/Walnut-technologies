# Walnut Technologies — Website

Frontend for **Walnut Technologies** (electronics design & manufacturing company):
a responsive, SEO-friendly React single-page application with serverless form
handling, deployed on Vercel.

**Live site:** https://walnutmedical.in

---

## Overview

The site covers the company's divisions (Medical, IoT, Fintech, Automotive, Neuro),
its manufacturing process, expertise, clients, resources, news and careers.
Content is file-based (no CMS): pages are React components, copy/data lives in
`src/data/*.js`.

---

## Features

- **Multi-page SPA** — home, about (+ evolution/future detail pages), solutions with
  division showcases, process, expertise (+ detail pages), clients, resources, news,
  contact, career/apply, privacy, terms
- **Responsive design** — mobile-first Tailwind UI with mobile bottom navigation
- **SEO** — per-page titles/descriptions/OG/Twitter tags via `react-helmet-async`,
  canonical URLs, `sitemap.xml`, `robots.txt`
- **Optimized images** — `Picture` component serves AVIF/WebP responsive variants
  generated by the Sharp pipeline (`npm run images`)
- **Forms** — contact, quote, resource and job application forms POST to a Vercel
  serverless function (`api/contact.js`) that sanitizes, rate-limits and emails
  via Resend
- **Chat widget** — rule-based assistant answering from a local knowledge base
- **PWA** — service worker, web manifest, install prompt, auto-refresh on new deploys
- **Animations** — framer-motion and scroll-triggered entrance transitions
- **Security headers** — CSP, HSTS, frame/deny and cache rules in `vercel.json`

## Getting started

Prerequisites: **Node 18+** (Node 22 recommended) and **Git**.

```bash
npm install
npm run dev        # http://localhost:3000
```

The dev server also runs the form API locally (custom Vite plugin in
`vite.config.js`), so forms work during development once `RESEND_API_KEY` is
exported in your shell.

### Scripts

| Script | What it does |
|---|---|
| `npm run dev` | Dev server on port 3000 (with local `/api/contact`) |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Serve the built `dist/` locally (port 4173) |
| `npm run images` | Image pipeline: optimize + responsive variants + manifest |
| `npm run optimize-images` | Convert/recompress source images → WebP |
| `npm run verify-images` | Load the built site in Chrome and flag broken images |

## Project structure

```
api/contact.js          Serverless form handler (Vercel) — emails via Resend
public/                 Static assets (images, sitemap, robots, sw.js, manifest.json)
scripts/                Image pipeline + QA scripts (node scripts/*.mjs)
src/
  App.jsx               Routes
  components/           Navbar, Footer, Hero, *Showcase.jsx, ProductTile, SEO, ChatWidget...
  data/
    content.js          Most site content (divisions, products, process, news...)
    chatKnowledge.js    Chat widget knowledge base
    translations.js     i18n strings
    imageVariants.json  Generated by `npm run images` — do not hand-edit
  pages/                One file per route
  utils/sendEmail.js    Frontend form API client
  index.css             Global styles / design tokens
vercel.json             SPA rewrites + cache/security headers
vite.config.js          Build config + local API plugin
```

## Quality checks

| Command | Checks |
|---|---|
| `npm run build` | Compile errors, bundle output |
| `npm run verify-images` | Broken images / preload issues on rendered pages |
| `node scripts/check-responsive.mjs` | No horizontal overflow at 16 viewport widths |
| `node scripts/check-image-refs.mjs` | Image paths referenced but missing |
