# Content claims review — pre-launch checklist

Every factual claim the website makes to the public, with its source, for a
human to verify before the site is promoted. Generated by a full scan of the
site copy (admin content, hardcoded component text, translations, chatbot).

**How to use**

- Go through each group; mark ✅ verified or ❌ needs change/removed.
- "Fix in" tells you where the text lives:
  - **Admin** = admin panel → Content (edits save to MongoDB; press Publish)
  - **Code** = a source file (needs a git push)
  - If it says **both**, they are separate copies and must match.
- ⚠️ = written by the AI assistant from the photo or industry-standard
  ranges, never confirmed against a datasheet — highest suspicion.
